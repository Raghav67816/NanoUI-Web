## NanoUI Is Evolving

NanoUI is an actively developed open-source project. We're continuously improving the rendering engine, expanding the widget ecosystem, refining the API, and building the tooling that makes embedded UI development enjoyable.

Documentation is growing alongside the framework, so expect new guides, examples, and API references with every release.
