# NanoUI Web

Documentation website for NanoUI and NanoTools, built with Vitepress.
This website covers guides, api references, fundamentals and tools usage for NanoUI.

Website is live on this [link](https://raghav67816.github.io/NanoUI-Web/)

## Stack
 - VitePress

## Development

To write or update documentation:

 - Clone this repository
 ```bash
 git clone https://github.com/Raghav67816/NanoUI-Web.git
 ```

 - Go to directory & Install dependencies
 ```bash
 npm install
 ```

To edit configuration please see `.vitepress/config.mt`

- To run locally
  ```bash
  npm run dev
  ```

## Directory Structure

### Fundamentals

Covers basics of the framework, provides an overview with an example.

For example, a Button will cover it's constructor and guide about how to create and modify a button.

### Tools

Covers usage of tools provided in [NanoTools](https://github.com/Raghav67816/NanoTools). This also contains examples.
